# 編集用イメージ写真

制作日：2026年10月9日。image_genで新規制作した風景・植物・小物のイメージ写真を使用する。人物、実在する葬儀場、特定の自治体や施設の撮影写真は含まない。写真を会場の実物や地域の実景の根拠として扱わない。

| 原本 | 内容 | 主な配置 |
| --- | --- | --- |
| `src/assets/editorial/landscape.png` | 朝の山並み、霧、川と草地 | ホームのファーストビュー、地域案内 |
| `src/assets/editorial/flowers.png` | 白いコスモスと陶器 | 葬儀・搬送の記事、メディア紹介 |
| `src/assets/editorial/woodland.png` | 木漏れ日の林 | お墓の記事、地域案内、本文中 |
| `src/assets/editorial/still-life.png` | 無地のノート、鉛筆、茶器 | 費用・手続き・終活の記事、記事一覧 |

原本は1536×1024px。Astroの画像機能で480・800・1200・1536pxのWebPを生成し、表示幅に合う画像を配信する。ファーストビューの画像は優先読み込み、本文中の画像は遅延読み込みとする。画像の寸法と表示比率を先に確保し、読み込み後のレイアウト移動を抑える。

公開ページに画像の説明文、キャプション、ラベルは付けない。画像内にも文字は含めない。装飾用途のためaltは空にし、読み上げでは既存の本文とナビゲーションを優先する。既存の地域地図は案内リンクとして別に保持する。
