# 編集用イメージ写真

制作日：2026年10月9日。image_genで新規制作した風景・植物・小物のイメージ写真を使用する。人物、実在する葬儀場、特定の自治体や施設の撮影写真は含まない。写真を会場の実物や地域の実景の根拠として扱わない。

24記事と8地域には、それぞれ冒頭と本文中に1枚ずつ、計64枚を追加で新規生成した。`src/assets/editorial/unique/guide-{slug}-{header|interlude}.webp` と `region-{slug}-{header|interlude}.webp` に専用画像を保存する。2026年11月4日に追加した記事（welfare-funeral）の2枚、2026年11月5日に追加した記事（funeral-schedule）の2枚、2026年11月6日に追加した記事（chief-mourner）の2枚、2026年11月7日に追加した記事（funeral-flow）の2枚は、OpenAIの画像生成API（gpt-image-2、1536×1024、quality high）で同じ方針（人物・文字なしの小物と室内）で新規生成した。funeral-scheduleは、冒頭を「障子窓のそばの白い菊の花器と麻布・木箱」、本文中を「夕方の縁側と庭」とプロンプトを事前に決め、各1回の生成で採用した（作り直しなし）。chief-mournerも、冒頭を「障子窓のそばの座卓の急須と湯のみ・藍色の風呂敷」、本文中を「午後の光が差す玄関の上がり框とスリッパ・白い花」とプロンプトを事前に決め、各1回の生成で採用した（作り直しなし）。funeral-flowも、冒頭を「すりガラスの窓のそばの棚に置いた白百合のガラス花器・青磁の香立て・無地の和紙」、本文中を「障子越しの夕方の光が差す板張りの廊下と、奥の花器の青い枝」とプロンプトを事前に決め、各1回の生成で採用した（作り直しなし）。既存4枚も各1箇所に限定し、40ページの76箇所すべてで異なる画像を使用する。同じ原本の切り抜きや色違いで別画像を作らない。

原本は主に1536×1024pxで、一部はさらに横長の構図とする。追加画像の生成原本は開発環境の `generated_images/` に保持し、リポジトリにはリサイズしない品質92のWebPソースを保存する。Astroの画像機能で480・800・1200・1536pxのWebPを生成し、表示幅に合う画像を配信する。ファーストビューの画像は優先読み込み、本文中の画像は遅延読み込みとする。画像の寸法と表示比率を先に確保し、読み込み後のレイアウト移動を抑える。

ページごとに画像キーを指定し、テーマ単位の共通画像へのフォールバックは行わない。指定した専用画像が欠けるとビルドを停止する。ビルド検証では全掲載箇所の画像バイト列をSHA-256で照合し、同じ画像の再使用を検出した場合も公開を止める。

全76枚のキー、ソース、被写体、寸法、ソースと生成原本のSHA-256は `docs/editorial-image-manifest.json` に保存する。原本の名前だけを記録し、環境固有の絶対パスは記載しない。

公開ページに画像の説明文、キャプション、ラベルは付けない。画像内にも文字は含めない。装飾用途のためaltは空にし、読み上げでは既存の本文とナビゲーションを優先する。既存の地域地図は案内リンクとして別に保持する。
