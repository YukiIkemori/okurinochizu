# 表示・デザイン検証

検証日：2026-10-08。紙の色を基調に、深緑と控えめな茶色、明朝の見出し、罫線で整理した情報メディアとして制作した。記事や地域を箱形のカードで囲わず、読み進める流れと余白を優先している。

## 実画面の確認

Chromium（`/usr/bin/chromium`）でホーム、葬儀費用の記事、地域の樹木葬の記事、安中市の地域案内を確認した。以下の全 16 条件でページ全体の横スクロールは発生しなかった。表は必要に応じて表の領域内を横スクロールできる。

| 表示幅 | 画面高さ | 確認した点 |
| --- | --- | --- |
| 1440px | 1000px | 2 列のヒーロー、目次、長文記事、地域地図 |
| 768px | 1024px | 見出しの改行、2 列のテーマ一覧、地域名の表示 |
| 375px | 812px | メニュー、1 列の記事、表、同意ボタン |
| 320px | 740px | 小さい画面での見出し、2 列の地域一覧、横幅 |

記事本文は PC・スマートフォンともに 16px。チェック項目と FAQ は 15px とした。日本語は OS の明朝・ゴシックを優先し、この環境では Noto CJK の表示を確認した。Web フォントのダウンロードは不要。

地域地図は位置関係を示す模式図として明示した。SVG の意味付けはリンクを含むグループとし、8 地域のリンクそれぞれに名前を付けている。OG 画像は 1200×630px、Apple touch icon は 180×180px。編集できる SVG 原本も `public/` に保存している。

スクリーンショットと検証の数値は `.local/visual/` に保存した（Git 管理対象外）。

2026年10月9日の改訂では、安中市・家族葬の記事末尾を1440pxと375pxで再確認した。相談案内は15pxの通常の段落と下線リンクに統一し、背景、囲み、独立した見出しを設けていない。各記事の相談リンクは末尾に1つだけで、全4条件で横スクロールは発生しなかった。

同日のホーム改訂では、搬送案内の説明文が末尾の「た。」だけで折り返される表示を修正した。文章幅の制限を取り除き、読点で区切った文節をひとまとまりにして表示する。1920、1440、1280、1100、1024、1000、768、375、320pxの9条件で横スクロールは発生せず、広い画面では一行、折り返す画面では文節単位になった。

## ローカルでの表示速度

最初の静的ビルドを Astro preview で提供し、375px 幅の費用記事を、新しい Chromium コンテキスト・通信と CPU のスロットリングなし・アクセス解析を拒否した状態で測定した。製品版の実ユーザーによる Core Web Vitals ではなく、このローカル環境での一回の観測値である。

| 指標 | 観測値 |
| --- | --- |
| FCP | 832ms |
| LCP | 832ms |
| CLS | 0 |
| HTML の転送量 | 7,815 bytes |
| CSS の転送量 | 5,191 bytes |
| favicon の転送量 | 636 bytes |
| 合計転送量 | 13,642 bytes（約 13.3KiB） |

JavaScript は小さなインラインモジュールとして HTML に含まれる。拒否状態では Google Analytics や外部フォントへのリクエストは発生しなかった。画像に依存しない記事表示で、初期読み込み中のレイアウト移動も検出されなかった。最終ビルドのアクセシビリティと操作確認は Playwright の検証結果を参照する。
