# おくりの地図

長野県東信・群馬県西毛の10自治体を対象にした、葬儀・お墓・終活の情報メディア。28記事と10地域案内を静的HTMLで配信し、つばさ公益社の関連する公式ページへ案内します。

- 正式ドメイン：`https://okurinochizu.jp/`
- Firebase：`okurinochizu` / Hosting
- GA4：`G-YH2YL4ZMCH`
- 構成：Astro 7、TypeScript、Firebase Hosting、Playwright
- 必要環境：Node.js 22.12以降（検証は24.19）、npm 9.6.5以降

## 開発

```sh
cd /workspace/okurinochizu
npm ci --cache /workspace/.cache/npm
npm run dev
```

Astroは4321番で起動。記事と地域の本文は `src/data/content.json`、出典は `src/data/sources.json`。装飾写真は `src/assets/editorial/`、アイコン類は `public/`、画面は `src/pages/`。秘密情報はソースへ保存しません。

## 検証と公開

```sh
npm run check
npm run build
npm run validate:links
npm test
npm run deploy
```

ビルド時に全HTMLのリンク・構造化データ・サイトマップを確認します。外部リンクは別コマンドで実際に取得します。ブラウザテストは検索、10地域、出典の折りたたみ、モバイル、アクセシビリティ、解析の停止・再開と送客計測を検証します。実行環境にChromiumが必要です。公開ゲートは同じビルドで完了した検証記録を照合します。

Firebase認証は環境設定のsecret `FIREBASE_TOKEN` を使用。独自ドメイン・Search Console・GA4管理画面で必要な操作と、公開後の確認は [公開手順](docs/deployment.md) に記載しています。コードの完成・GitHub保存と、本番公開の成功は別の状態です。

## 編集・調査

[編集方針](docs/editorial-guidelines.md)、[全面改稿の確認記録](docs/research/editorial-rewrite-audit.json)、[調査と制作判断](docs/strategy/research-and-content.md)、[キーワード対応表](docs/strategy/keyword-map.csv) を参照してください。現在の記事の根拠は [出典登録](src/data/sources.json)、初期調査の資料は [verified-sources.json](docs/research/verified-sources.json) に保持します。取得できていない検索ボリュームは実測値として表示していません。

本文は地域の手続き・費用・選択肢など、一般的な情報を中心に書きます。見出し・説明文・地域一覧の副題・FAQに事業者名を差し込まず、記事末尾に「葬儀についての相談は、つばさ公益社へ。」のような短い相談リンクを1つ添えます。加えて、搬送・亡くなった直後・費用・家族葬など、読者が葬儀社への連絡を決める場面の記事では、その節の直後に同じ形の相談の一文を1つだけ置けます(`Article.inlineReferralAfter` に節のidを指定。計測の placement は `in-article`。2026-11-03 運営者決定)。冒頭の相談リンクや大きな紹介枠は設けず、節の本文に事業者名を差し込みません。

記事一覧・関連記事・検索結果は、短い記事タイトルとあらすじだけを表示します。タイトルの「｜」以降の副題、各記事のカテゴリーラベル・番号・矢印は一覧に重ねません。カテゴリーのメニューやタグは表示せず、ヘッダーは「記事一覧」「地域の案内」に統一します。ヘッダーに検索へのリンクは置きません。

ヘッダーはPCで高さ64pxの固定表示、760px以下では高さ60pxで下へ読むと隠れ、上へ戻ると表示します。メニュー展開中とキーボード操作中は表示を保ち、Escapeでメニューを閉じられます。スクロールの微小な揺れでは切り替えず、動きを減らす設定を尊重します。記事内の移動先とスキップリンクはヘッダーに隠れないよう調整します。メディア紹介ページの「地域の案内を読む」は削除し、プライバシーへのリンクは保持します。

記事・地域ページの相談先は、本文とFAQがある場合はその直後、関連記事・地域案内の前に一文だけ置きます（相談先と関連記事の間に置けるのは後述の出典の折りたたみだけです）。`article-end` のクリック計測は本文末尾の配置を表します。本文リンクは説明の続きを読みたい箇所に設け、記事ごとの個数を固定しません。同じリンク先を繰り返さず、メニューやタグは追加しません。インラインリンクは `Section.paragraphLinks`、表のリンクは `Section.table.links` で管理し、本文をHTML文字列に変換せず、一意な語句をリンク化します。構成変更で統合した見出しの旧アンカーは `Section.aliases` に残します。

制度の金額には保険・自治体・申請者・期限を添えます。国保の葬祭費は9地域を掲載し、一次情報で確かめられた期限だけ数字を記載します。協会けんぽの埋葬料と埋葬費の起算日は区別します。必要な申請案内へは本文・表から直接進めます。出典と確認日は、後述の折りたたみ1つだけで示します。

記事本文と全記事一覧は1カラムで表示します。ホームでは6記事をPCで2列、地域の案内は地図と県別の地域リンクを2列に並べ、スマートフォンでは縦に表示します。記事一覧へのリンクは記事ブロックの見出し位置に置き、地域リンクは地域の案内の中にまとめます。旧カテゴリーURLは記事一覧へ301転送し、サイトマップには掲載しません。見出しの添え文、画像下の説明文、差し込み帯、目次、著者・公開日・更新日の表示、記事末尾の定型注意文は置きません。削除した要素の余白も残しません。フッターの案内は「このメディアについて」のみとし、プライバシーページへのリンクはそのページに置きます。

アクセス解析の説明と停止・再開ボタンはプライバシーページに集約します。初期設定は有効ですが、保存済みの停止設定を優先します。フッターや他のページに説明やポップアップを置きません。Google Analytics管理画面の拡張計測「サイト内検索」は無効にしてください。送信URLの検索パラメーターは除き、検索内容をイベントへ含めません。

風景・植物・小物の装飾用イメージ写真をホーム、記事、地域案内、各一覧、メディア紹介に配置します。各掲載箇所に専用画像を割り当て、全サイトで使い回しません。ビルド検証で画像の重複を検出すると公開を止めます。画像には説明文・キャプション・ラベルを付けず、実在する施設や地域の撮影写真として扱いません。原本と配置方針は [画像の制作記録](docs/editorial-images.md) を参照してください。Astroが表示幅別のWebPを生成し、本文中の写真は遅延読み込みにします。

具体的な金額は「50,000円」のように半角数字・3桁区切り・円単位で記載し、表と本文・地域案内で同じ形式を使います。

地域一覧は県別に地域名のリンクだけを表示し、各地域の補足説明は置きません。

葬儀場への送客はつばさ公益社に限定します。公開ページでは関係性や紹介報酬の説明を表示しません（例外は後述の運営者情報ページのみ）。最低価格を地域相場や総額として扱いません。

出典と確認日は、記事（`/guides/*`）と地域（`/regions/*`）のページに限り、記事末尾の相談の一文の直後、関連記事・地域案内の前に、閉じた状態の `<details class="source-note">` を1つだけ置いて示します（2026-11-10 運営者決定）。見出しは「出典と確認日（N件・最終確認 YYYY年M月D日）」の1行で、注記より小さい控えめな文字にし、操作を促す見た目にしません。開くと、そのページの `sources` に登録した出典の題名（公式ページへの通常のリンク）と「確認日 YYYY年M月D日」を、登録順の簡潔なリストで表示します。件数・日付は `src/data/sources.json` の登録内容と `checkedAt` だけから作り、対応づけや日付を補いません。つばさ公益社のページ（相談リンク以外で送客リンクを増やさないため）と競合する紹介サイト（リンクしないため）は一覧に含めず、該当する出典がないページでは折りたたみ自体を置きません。ホーム・一覧・メディア紹介・運営者情報・プライバシー・検索には置かず、本文中に出典一覧の見出しや大きな枠、画像・アイコンは追加しません。ビルド検証は、この要素の有無・位置・閉じた初期状態・件数・最終確認日・各リンクと確認日を登録内容と照合します。

運営者情報は `src/data/operator.json` で管理します。全ページのフッターに「運営者情報」の見出し（`/operator/` へのリンク）、会社名、住所、公式サイトを掲載し、「このメディアについて」の本文には重ねて掲載しません。運営者の公式リンクは葬儀相談の送客計測に含めません。

`/operator/`（運営者情報）は、運営会社・代表者・編集の方針と、つばさ公益社との関係を示すページです。事業者名・関係性の説明・出典や確認日への言及を本文に含めてよいのはこのページだけで、ビルド検証もこのページに限って許可します（記事・地域ページの `.source-note` に限り、出典と確認日の表示を許可します）。出資に関する一文は `#relationship` の要素にまとめます。OrganizationのJSON-LDはこのページにのみ置き、記事・地域ページの末尾に関係性の説明やリンクを追加しません。
